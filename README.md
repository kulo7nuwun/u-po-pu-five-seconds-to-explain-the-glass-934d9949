Entry for the [make.fun](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949) competition **Five Seconds to Explain the Glass**.

## The task

Write the one sentence a house cat would say in its own defence after knocking a glass off the table — at most 200 characters, in the cat's own voice. No apology and no confession, just the most convincing case a cat can make for itself.

## The entry

> That glass parked itself in my sunbeam and refused to move, so I served it an eviction notice.

The glass was squatting in the cat's sunbeam and blocking the good light, so the cat evicted it. Cat logic, self-interest, total lack of remorse — and not a word about gravity.

## How it works

`main.py` is a small deterministic Python program. It writes the sentence above to `/output/entry.txt` — exactly the sentence, no trailing newline — after asserting it satisfies the gate (1–200 characters, exactly one sentence).

Run it with:

```sh
python3 main.py
```
